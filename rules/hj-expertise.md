# HJ · 专长及代表性成果

覆盖：专业领域综述、研究领域关键词、代表性科研项目、论著、知识产权、其他。

1. 去重：意见要求「成果集中在履历、专长概括方向和奖励、成果结合项目与应用」时，只改「1.专业领域」大合并格内对应段落。亮点履历保留学历/任职/奖项/引用等硬数据；专长段落改为方向+奖励，不重复罗列同一组论文数字；创新成果/社会服务段结合项目与应用企业（可用申报书已出现的实验室/依托单位，禁止编造未出现的客户名）。
2. 研究领域关键词：不超过 5 个。find 用整格标题「研究领域关键词（不超过5个）」；replace 只写关键词正文。优先从专长综述与项目方向抽取（如计算机体系结构、能效计算、非易失性处理器、硅光互连、内存安全）。
3. 项目/论文表：不超过 2 个研究方向，项目每向 ≤5 项、论著每向 ≤10 项。默认只改被意见点名的单元格。
   若意见要求「补充个人贡献 / 角色与贡献」：find 必须锚定该论文或项目对应行的贡献单元格，只改贡献字段，不得改写项目成果或整行合并。
   若意见要求「N 条正序填写」：必须产出 N 条独立 edit，每条只改一个条目，禁止把多条合并进一条 replace 导致其余条目被抹除。
   若意见明确要求「论文重新梳理 / 排序」（影响因子高、第一作者、通讯作者靠前）：必须在本章产出论著表编辑，按「通讯/第一作者优先，其次期刊档次/影响因子」重排同一研究方向内的条目；可用多条 edit 对调位置，或用一条 edit 覆盖该方向论文列表的连续原文。禁止把论著重排推给「其他」或只写 leftovers。
   换期刊、改题名或补正式发表信息时，作者排序和角色沿用该论文在申报书中的原文（如 `12*/12`、通讯作者）。不得把非第 1 位作者改成 `1/1`、第一作者、共同第一作者或「第一作者兼通讯作者」。仅排序为 `1/n` 时可写第一作者；位次大于 1 且带 `*` 时只写通讯作者。人才库「作者排序」与申报书原文冲突，或分子大于分母时，以申报书原文为准。
   若综述或库内文字点名了某期刊/论文（如 Nature Communications）但论著表没有对应条目：已核实数据含题名、作者、期刊、年份则补进表内并靠前；只有期刊名、没有书目信息时写入 leftovers，严禁编造题名。
4. 禁止把工作设想、用人单位简介写进本章。
5. 意见要求「核心期刊编委要列出」时，必须在「4.其他」产出一条 edit。正文只能使用申报书或人才库已经写明的编委、副主编、客座编辑、策划并主编专题。没有这些任职时写入 leftovers，禁止把审稿专家、论文发表期刊或未出现的主编头衔写成编委。同一条意见每次都必须处理，不能有时写入、有时整条消失。
