# 【工作计划】规则包（申报人拟实现工作目标及可行性论证 · 限1500字）

本栏为启明（QM）青年人才申报书 **第六章合并大字段**，整栏上限 **1500 字**（去空白计），目标 **1200–1350 字**。

## 栏位结构（必须保留小标题，禁止删改章节号）

1. **【项目名称】** — 须为精细化技术方向，禁止空泛表述（如仅写「关键技术研发」而无具体对象）。
2. **【项目概述】** — 须点明企业 AR-HUD / 智驾座舱场景、现有瓶颈（对齐误差、恶劣天气、尺度歧义等）及与 **行车安全** 的关系；禁止就技术说技术。
3. **（一）未来三年工作目标** — 研发目标、预期成果（软著/标准）、产业化分年目标、团队培养、产业与社会效益；指标须可量化。
4. **（二）制定目标依据** — 行业背景与企业升级阶段、自主可控意义。
5. **（三）拟解决的关键技术问题** — 分条列出 2–3 项，每条含技术路线与量化指标。
   - 意见要求「重新拆分三个技术问题」「1、3 重复」时：**必须产出 3 条独立 edit**，分别锚定 `1.` / `2.` / `3.` 开头的问题条目。
   - 第 3 条不得与第 1 条语义重复（「对齐不准」不得与「对齐难题」并列重复）。
6. **（四）创新之处** — 国内外对比 + 技术急需紧缺性。
7. **（五）可行性论证分析** — **【申报人在该领域研发经验和工作基础】** 须按时间/阶段叙述既往业绩如何支撑本项目（论文、项目、奖项、工程化成果），让专家相信可胜任；**【用人单位投入积累】** 须与企业实际研发平台、定点客户、专利数据一致。
   - 意见补充「政策、市场、技术发展趋势」时：find 必须落在 **（五）可行性论证分析** 小节，**禁止只改（二）制定目标依据【背景】**。

## 市专题常见修改要求（必须落实为 edits，不得整栏标「已符合」）

- 项目名称改为更精细的方向（紧扣 AR-HUD 虚实融合、动态对齐、安全等）。
- 补充 AR-HUD 发展背景与安全必要性（人机共驾、眩晕、感知失效等）。
- 研发经验与工作基础按「在该领域的阶段成果」重写，避免与前面章节机械拼凑。
- 与申报企业（泽景）第四代 DLP AR-HUD、车载场景强关联；正文中除规定栏位外不写企业名称。

## 编辑技巧

- 本栏为合并单元格：一次 edit 只替换 **一段连续原文**（通常一个小标题及其下 1–3 段），find ≤200 字且能唯一定位。
- 禁止把（一）～（五）整栏写进一条 replace。
- 字数：单条 replace 替换后，该段落在全栏 1500 字预算内；若需大改，拆成多条 edit（项目名称、概述、工作基础等各一条）。
