# 【用人单位 · 拟提供申报人支持条件】（QM 第七章，限 300 字）

本栏位于 **七、用人单位情况及承诺 → 拟提供申报人支持条件（300字以内）**，与第六章 1500 字工作计划 **不是同一栏**。

## 结构（保留【】小标题）

- **【工作环境】** 办公与实验场地、地理位置（如仪征产业园、CNAS 实验室等）
- **【设备保障】** GPU 算力、光学仿真、车载检测设备等
- **【团队保障】** 算法团队规模与配置
- **【生活配套】** 公寓、补贴、子女入学等
- **【政府支持】** 省市县奖励与购房补贴（与表内已有数据一致）

## 编辑规则

1. find 必须锚定 **拟提供申报人支持条件** 栏内连续原文（通常某一【小标题】及其内容），禁止改到第六章工作计划或推荐理由。
2. 意见要求「贴合实际、去空话」时：用企业表内已有信息（注册地址、CNAS、专利、定点客户等）改写，**库中无依据的数字（如经费金额）写入 leftovers 或转人工复核**，禁止臆造。
3. 可拆成多条 edit（工作环境 / 设备 / 团队各一条），但每条 find 仍须在本栏内。
4. 整栏替换后不得超过 **300 字**（去空白计）。
