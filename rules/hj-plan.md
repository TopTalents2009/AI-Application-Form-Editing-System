# HJ · 工作设想

覆盖回国/来华后工作目标、研究背景、研发内容、技术路线、预期目标、基础条件。正文在同一大合并格内。

1. 量化：研发目标、研发内容、技术路线须写入可核验的指标（倍数、百分比、时延、开销、论文/专利数量等）。优先复用本章「四、预期目标」和专长综述里已有的数字，禁止编造申报书与人才库都没有的新指标。
2. 职务与任务：写明引进后担任职务（封面「职务(岗位)」格已有则必须用该职务，如技术总监）及开展工作内容。
3. 背景：补国内外对比、公司/实验室战略目标与研究意义，但不要把意义写成空话挤掉量化句。
4. 一次编辑只替换 find 覆盖的那一段（如「2、研究目标及意义」到下一大点之前），不要把整章工作设想一次性塞进一条 replace。
5. 不要改「（8）申报单位」以后的内容。
